Create a modern, premium, minimalistic multi-vendor salon marketplace web app UI in Figma Make named “SalonMama”.
The platform is Bangladesh-focused and allows customers to browse salons, select services, upload face photos for AI hairstyle recommendations, book appointments, and pay through Bangladeshi payment methods.

Use a clean white background with modern blue gradient aesthetics similar to premium travel/lifestyle SaaS landing pages.
Design language should feel elegant, soft, trustworthy, premium, and highly user-friendly.
Use rounded corners, soft shadows, glassmorphism where needed, subtle gradients, clean typography, and responsive layouts.

Primary Color Palette:

* Gradient Blue: #36A2FF → #007BFF
* Soft Sky Blue: #EAF6FF
* White Background
* Accent Purple/Blue Glow
* Light Gray Borders
* Text: #1E293B

Style Reference:

* Similar aesthetic to modern AI SaaS landing pages
* Minimal but visually rich
* Smooth gradients
* Spacious layout
* Mobile-first responsiveness
* Card-based sections
* Elegant animations/transitions implied in design

Typography:

* Modern sans-serif like Inter or Poppins
* Large bold hero text
* Clean readable body text
